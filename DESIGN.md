# Design System — PULSE 大学生游戏化运动激励工具

Generated by /design-consultation on 2026-05-09
Source: PULSE 测评作业 + 24 approved mockups + v4 plan-design-review

## Product Context

- **What this is**: 游戏化运动激励工具，把"运动"包装成 Duolingo + 皇室战争语法的"每天必须打开 app 才能维持的东西"
- **Who it's for**: 大学生，在 Keep / Nike+ / 微信运动里坚持不下来运动的那批
- **Space/industry**: 健身 / 习惯养成 / 游戏化产品
- **Project type**: Web app（响应式，desktop-first，1440 设计稿，移动适配）
- **Memorable visual**: Streak 数字像 arcade 招牌发光（dashboard 中央 hero 元素）

## Aesthetic Direction

- **Direction**: Dark Cyber Neon
- **Decoration level**: Intentional minimal（1px borders + 局部 neon glow halo + 4px 卡片圆角，无装饰 blob/gradient/stock 插画）
- **Mood**: 暗黑 dashboard / 街机招牌 / 卡牌战斗 UI，不是"健身 app"
- **Reference**: PULSE prototype `/index.html`, 24 approved mockups in `~/.gstack/projects/Billkst-meituan-coding-gamified-exercise-motivation-tool/designs/pulse-v1-20260509/`

## Typography

```
Display:    Satoshi Bold      ALL CAPS for headers / hero numbers
Body:       Instrument Sans   14-16px Regular
UI/Labels:  Instrument Sans   12-13px ALL CAPS letter-spacing +0.05em
Data:       JetBrains Mono    timer, stats, hex codes, tabular-nums
Code:       JetBrains Mono
```

- **Loading**: Bunny Fonts (无 GDPR cookie tracking)
  - `https://fonts.bunny.net/css?family=satoshi:700|instrument-sans:400,500,600|jetbrains-mono:400,700`
- **Fallback chain (中文环境)**: Satoshi → -apple-system → "PingFang SC" → "Microsoft YaHei" → sans-serif
- **Scale**:
  - hero (streak): clamp(80px, 14vh, 180px)
  - h1: 48px / 1.1 line-height
  - h2: 32px / 1.2
  - h3: 24px / 1.3
  - body-lg: 16px / 1.5
  - body: 14px / 1.5
  - caption: 12px / 1.4
  - data-mono: 16-32px tabular-nums

**为什么不是 Inter**: Inter 在 AI 设计 slop blacklist 上（与 Roboto/Helvetica/Space Grotesk 同列）。Satoshi 几何感更强，Instrument Sans 是 2025 独立产品偏好的搭档，组合给 PULSE 独特字体记忆点。

## Color

### Approach: Restrained
1 个主 accent + 暗色 neutrals + rarity 4 色作为信息编码（不是装饰）。

### Tokens

```
--bg-primary:      #0a0e1a   /* deep navy, page bg */
--bg-secondary:    #14182a   /* panel surfaces */
--bg-tertiary:     #1a2030   /* hover / active surfaces */

--accent-primary:  #b6ff3c   /* neon lime — CTAs, active, streak, buff */
--accent-pink:     #ff3c8c   /* EPIC rarity 二级辅 only — NEVER buff main */

--text-primary:    #ffffff   /* hero / heading */
--text-secondary:  #a0a8c0   /* body */
--text-tertiary:   #666870   /* caption / disabled / empty state icon */

--rarity-common:    #888888
--rarity-rare:      #3c8cff
--rarity-epic:      #9c3cff
--rarity-legendary: #ffc83c

--semantic-success: #b6ff3c   /* same as accent-primary */
--semantic-warning: #ffc83c   /* same as rarity-legendary */
--semantic-error:   #ff4040
--semantic-info:    #3c8cff   /* same as rarity-rare */

--border-default:   rgba(255,255,255,0.1)
--border-active:    #b6ff3c
--border-rarity-*:  matching rarity color
```

### Light mode
**❌ v1 dark only**. No `prefers-color-scheme` media query, no toggle. Light mode = v2 候选 (post-evaluation)。

## Spacing

- **Base unit**: 8px
- **Density**: Comfortable game UI（紧凑但非 dense）
- **Scale**: `2xs(2) xs(4) sm(8) md(16) lg(24) xl(32) 2xl(48) 3xl(64) 4xl(96) 5xl(128)`
- **Container max-width**: 1280px
- **Sidebar**: 240px desktop / 60px tablet (icon-only collapsed) / hidden mobile
- **Right panel**: 360px desktop / drawer tablet / hidden mobile

## Layout

- **Approach**: Grid-disciplined frame + dramatic focal
- **Grid**:
  - Desktop (≥1024px): 12 col, 24px gutter
  - Tablet (768-1024px): 8 col, 16px gutter
  - Mobile (<768px): 4 col, 16px gutter
- **Card grid**: 5 col desktop / 3-4 col tablet / 2 col mobile
- **Border radius**:
  - Card: 4px (sharp not bubbly — AI slop blacklist)
  - Button: 8px
  - Pill / chip: 999px (full pill)
  - Modal: 4px
  - Avatar: 999px (circle)
  - Input: 4px

## Motion

- **Approach**: Intentional minimal
- **Easing**:
  - Enter: `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out fast)
  - Exit: `cubic-bezier(0.4, 0, 1, 1)` (ease-in)
  - Move: `cubic-bezier(0.4, 0, 0.2, 1)` (ease-in-out)
- **Duration**:
  - micro: 50-100ms — toggle, color change
  - short: 150-250ms — hover, page transition
  - medium: 250-400ms — modal, slide
  - long: 400-700ms — level-up
  - signature: 1500ms — card shuffle reveal
  - breathing: 4000ms — streak pulse

### Specific motion specs

| Motion | Duration | Easing | What |
|---|---|---|---|
| Streak number breathing | 4000ms infinite | ease-in-out | brightness 80%↔100% + scale 1.00↔1.02 |
| Card shuffle (loot reveal) | 1500ms | ease-out | opacity 0→1 + scale 0.9→1.0 + rotate -3°→0 |
| Level-up burst | 800ms | cubic-bezier(0.34,1.56,0.64,1) | scale 1→1.2→1.0 + glow flash |
| Buff icon pulse | 1200ms infinite | ease-in-out | opacity 70%↔100% |
| Hover quick | 150ms | ease-out | scale 1.00→1.03 |
| Page transition | 250ms | ease-out | translate-x 20px→0 + opacity 0→1 |
| VICTORY confetti | 1000ms | linear | particle burst, 30 pieces neon green |

## Glow Spec (Neon Halo) — 4 档

```css
/* SUBTLE — hover state on small elements */
box-shadow: 0 0 4px rgba(182, 255, 60, 0.3);

/* STANDARD — primary CTA, active states */
box-shadow: 0 0 12px rgba(182, 255, 60, 0.5);

/* HERO — streak number, level-up, big moments */
box-shadow:
  0 0 24px rgba(182, 255, 60, 0.7),
  0 0 48px rgba(182, 255, 60, 0.3);

/* LEGENDARY — gold-tier, only 传说卡牌 */
box-shadow:
  0 0 16px rgba(255, 200, 60, 0.8),
  0 0 40px rgba(255, 200, 60, 0.4);
```

## Streak Number Hero (Critical — Memorable Anchor)

PULSE 的视觉记忆点。Treat as immutable spec.

- **Number font-size**: `clamp(80px, 14vh, 180px)`
  - 1440x900 desktop ≈ 126px
  - mobile ≈ 80px
- **Number font**: Satoshi Bold + tabular-nums + ALL CAPS
- **Number color**: `var(--accent-primary)` #b6ff3c
- **Glow**: HERO level
- **Label "DAY X STREAK"**: 1/6 of number size, JetBrains Mono ALL CAPS, letter-spacing +0.1em, above the number
- **Animation**: 4s breathing (brightness 80%↔100% + scale 1.00↔1.02)
- **Position**: Dashboard center, the full hero block (label + number + sub-label) ≈ 25% screen height
- **At-rest discipline**: dashboard 上其他元素如 total cards / weekly XP 字号 ≤ 32px，不与 streak 争视觉重量

## Buff Differentiation

Buff 状态与 primary accent 共享 #b6ff3c。区分通过**结构**而非**颜色**：

| Differentiator | Buff | Primary CTA |
|---|---|---|
| Icon overlay | 10x10 IconCompass / IconSparkles 左上角 | 无 |
| Border | dashed 1px | solid 1px |
| Animation | 1.2s pulse breathing | 150ms hover scale |
| Pill shape | tag/chip rounded 999px | button rounded 8px |

## Empty / Loading / Error States

### Skeleton screen
- Card bg: `#1a1f30` solid
- Shimmer: 1.5s 横向 sweep, gradient `rgba(182,255,60,0.1) → transparent`, 重复无限
- 无骨架边框（避免 visual noise）

### Empty state
- 64x64 Tabler icon, color `var(--text-tertiary)` #666870
- 16px Instrument Sans 文字 (例: "Finish first workout to draw cards")
- 主 CTA 按钮（带 STANDARD glow）

### Error toast
- 位置：右下浮窗
- 背景：`#3a1212` (dark red)
- Border-left: 2px solid `--semantic-error` #ff4040
- 16px text + retry button + 5s 自动消失
- 进入：250ms slide-in from right
- 退出：250ms fade out

### Inline error
- 13px `--semantic-error` text
- IconAlertCircle 14px 左侧
- 在表单字段下方 4px gap

### Loading spinner
- ASCII rotating `|/-\` in JetBrains Mono 16px
- 100ms per frame
- color: `var(--accent-primary)`
- 不用 GIF spinner — 与产品赛博风一致

## Arena Victory / Defeat Mirror

同一布局组件，props 切换：

| Prop | VICTORY | DEFEAT |
|---|---|---|
| Background | `--bg-primary` (unchanged) | `--bg-primary` (unchanged) |
| Hero text color | `--accent-primary` #b6ff3c + HERO glow | `--text-tertiary` #666870 (no glow) |
| Hero text content | "VICTORY" | "DEFEAT" |
| Arrow direction | up + glow | down (no glow) |
| Particle effect | 1s confetti, 30 neon green pieces | none |
| Sub-text | "+XP gained" | "-XP lost (50% frozen)" |

**反惯例**: DEFEAT 不变红背景。理由：PULSE 是激励工具，DEFEAT 不应制造"游戏失败"羞耻感。

## Responsive Breakpoints

```
mobile:  < 768px       single column, bottom tab bar (5 nav)
tablet:  768 - 1024px  sidebar 60px collapsed icon-only, right panel as drawer
desktop: ≥ 1024px      sidebar 240px expanded, right panel 360px
hero:    ≥ 1440px      design 基准稿尺寸
```

### Mobile 折叠规则
- Sidebar 240px → bottom tab bar (5 nav: Dashboard / Sports / Loot / Arena / Profile)
- Right panel 360px → 隐藏，作为下一层屏（点 expand 进入）
- Card grid 5 列 → 2 列
- Form 单列 stack
- Streak number `clamp()` 自适应到 ~80px
- Onboarding 全屏，progress dots 改顶部 progress bar

## a11y Baseline (WCAG AA)

- **Contrast**: all text ≥ 4.5:1
  - #b6ff3c on #0a0e1a = 14:1 ✓ (AAA)
  - #a0a8c0 on #0a0e1a = 9.5:1 ✓ (AAA)
  - #666870 on #0a0e1a = 4.6:1 ✓ (AA, 仅用于辅助 text)
  - rarity colors on #0a0e1a 全部 ≥ 4.5:1 ✓
- **Keyboard nav**: Tab cycles through nav → main → right panel → footer; Esc closes modals
- **Touch target**: ≥ 44px mobile, ≥ 32px desktop
- **ARIA**: 所有 icon-only 按钮带 aria-label。语义化 `<nav> / <main> / <aside>` landmarks。
- **Screen reader smoke**: VoiceOver / NVDA 跑通 onboarding + workout submit + 抽卡 三个流程
- **Focus indicator**: 2px solid `--accent-primary` outline + STANDARD glow
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` 关掉 streak breathing / shuffle / level-up burst，只保留 transitions

## Implementation Stack (绑定决策)

| 层 | 选择 | 理由 |
|---|---|---|
| Framework | Vite + React 18 + TypeScript | v4 doc 锁定 |
| Styling | Tailwind v3 + CSS variables | tokens 通过 CSS vars 暴露给 Tailwind config |
| Icons | @tabler/icons-react | 26 项运动覆盖 |
| Fonts | Bunny Fonts (Satoshi / Instrument Sans / JetBrains Mono) | 无 GDPR |
| Animation | CSS transitions + Framer Motion (only for streak breathing / shuffle / level-up) | 性能优先 |
